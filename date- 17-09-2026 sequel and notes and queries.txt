Client–Server Model in SQL — Short Summary

```text
User → Client → Database Server → Database
                    ↓
User ← Client ← Database Server
```

* User: Person who requests data.
* Client: Software like MySQL Workbench that sends SQL queries.
* Database Server: Processes the SQL query and manages the database.
* Database: Stores tables and actual data.
* Result: Server sends the requested data back to the client, which shows it to the user.

Example:
User writes `SELECT * FROM students;` → Client sends it → DB Server processes it → Database provides data → Result shown to User.

1.Clauses are used for tasks such as filtering, storing, grouping, joining, manipulating and defining any database object.
2. clauses are used :
	1. control the flow of the data
	2. Apply condition and sort the data and attribute
	3. define the order of the records.
	4.

2. Types of Clauses :-
	1. SELECT:- USED TO SELECT ATTRIBUTES FOR THE DISPLAY
	2. FROM:- USED TO SELECT  TABLE FROM DATABASE
	3. WHERE:- USSED TO FILETER VALUES OF THE ATTRIBUTES 
	4. GROUP BY:- USED TO GROUP VALUE  ACCORDING TO THE ATTRIBUTES
	5. ORDER BY:-  USED TO ORDER THE RECRDS
		       ** ONLY CLAUSE WHICH CAN WORK WITH VIRTUAL VALUES AND REAL VALUES OF THE DATA. ******
	6. HAVING:-  TO APPLY AGGREGATE FUNCTIONS ON ATTRIBUTES
	7. JOIN:- USED TO JOIN MULTIPLE TABLE 
	8. DISTINCT:- USED TO FILTER  OUT THE DISTINT RECORDS FROM THE DISPLAYED RESULT
